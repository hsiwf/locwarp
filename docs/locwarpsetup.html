LocWarp 安装教学

在 Windows 上模拟 iPhone 定位。照下面四步做完就能用,大约 5 到 10 分钟。

电脑:Windows 10 / 11(64 位元) 设备:iOS 17 以上,iOS 16 由社群维护 连接:USB,或同一个 WiFi

四个步骤

1

下载并安装 LocWarp

抓最新版的 Windows 安装包,档名像 LocWarp Setup X.X.XXX.exe。两个来源内容相同。

GitHub Releases Google 云端
出现「Windows 已保护您的电脑」 LocWarp 没有做数字签名,第一次执行会被 SmartScreen 挡。点「其他信息」再点「仍要执行」即可。
安装与执行都需要系统管理员权限 WiFi Tunnel 需要建立虚拟网络接口,所以安装时会要求管理员权限,每次打开也会跳 UAC。
防毒软件把后端程序隔离 打开后若提示后端程序不存在,是防毒把未签名的 exe 删了。先把安装文件夹加入防毒的排除列表,再重新安装一次。
2

安装 Apple USB driver

Windows 没有内建 Apple 的 USB driver。下列三种择一安装即可,多数人装桌面版 iTunes 就能用。

桌面版 iTunes(64-bit) Store 版 iTunes Apple Devices
iTunes 抓不到 iPhone 社群回报改装 Microsoft Store 的 Apple Devices 可以成功。
3

USB 连接并信任电脑

用原厂或支持资料传输的 USB 线接上 iPhone。iPhone 跳出「要信任这部电脑吗?」时点「信任」并输入密码。

没跳提示、或电脑抓不到手机 先打开 iTunes 或 Apple Devices 看有没有检测到设备。连 iTunes 都看不到,多半是线或孔的问题:
  • 很多副厂线、附赠线只能充电,没有资料脚位。换原厂线或标示支持资料传输的线。
  • 接头松动或进灰尘会时好时坏,换线并清干净两端。
  • 改插主机板后方的 USB 孔,避开前面板、延长线、USB hub 与屏幕上的孔。
  • USB 3.x(蓝色孔)对 iPhone 有时反而不稳,试试 USB 2.0(黑色孔),反过来也试。
  • iPhone 要解锁并停在桌面。之前误按「不信任」的话,到「设置 › 一般 › 移转或重置 iPhone › 重置 › 重置位置与隐私权」,重插就会再问一次。
  • 最后才试 iPhone 与电脑各重开一次。
4

打开开发者模式

在 iPhone 上前往:

设置›隐私权与安全性›开发者模式

打开开关,iPhone 会要求重新启动。重启后再确认一次「启用」并输入密码。

设置里找不到「开发者模式」 iOS 16 以上默认不显示这个选项。用 USB 把 iPhone 连上 LocWarp,到程序上方的「设置」页按「打开开发者模式」。接著在 iPhone 上把「设置」App 完全关掉再重开,进到「隐私权与安全性」往下拉就会看到。
完成 打开 LocWarp、USB 接上 iPhone,程序会自动抓到设备,在地图上按右键就能瞬移。要改用无线时,到「连接」页启动 WiFi Tunnel,成功后即可拔掉 USB(需 iOS 17 以上,且先用 USB 配对过一次)。

常见问题

打开程序直接闪退、黑画面或卡住 通常是显示卡驱动与硬件加速不合。对桌面的 LocWarp 捷径按右键 › 内容 › 目标,在最后面(结尾引号之后)空一格补上: --no-sandbox --disable-gpu --in-process-gpu 按「确定」后再从这个捷径打开。
画面残影或黑画面到「设置」页关闭硬件加速,重启程序。
Tunnel 启动后连不上确认以系统管理员身份启动,暂时关闭 VPN 或第三方防火墙再试。
WiFi 自动检测找不到设备确认在同一个 WiFi 网段,路由器没开设备隔离(AP isolation)。可改为手动输入 IP。
WiFi Tunnel 屏幕暗掉就断线把 iPhone 的「自动锁定」设为永不并接上充电,或在 LocWarp 打开「屏幕暗掉维持连接」。
No such service: dtservicehubDDI 没挂上。失败时先关闭开发者模式、重开机、再打开,然后重新挂载。
国旗或地名没出现这两项来自免费公共服务,偶尔会暂时无回应,稍后再瞬移一次即可。

回报问题请附上 iOS 版本、连接方式,以及 ~/.locwarp/logs/backend.log。状态列的「Log 文件夹」按钮可以直接打开该文件夹。

功能简介

移动模式

瞬间移动直接跳到指定坐标。
导航移动沿真实道路前往目的地,走路、自行车、开车三档速度。
多点路径依序经过多个点,每站可停留(默认随机 5 到 20 秒)。圈数设 0 跑一趟,设 N 绕 N 圈,留空无限循环。可勾「点对点跳跃」改成逐点瞬移。
花农专用在每个路径点周围绕圈。绕圈距离、段数、圈数、轮数、前后等待都可自订,点与点之间可走过去或瞬移。
随机漫步在指定半径内随机漫游,每段停顿可调。
摇杆操控以方向与力度即时操控,支持 WASD 与方向键。

速度

  • 三档默认:走路 10.8、自行车 19.8、开车 60 km/h。
  • 可输入任意固定速度,或最小到最大的随机范围,每段路重新抽一次。
  • 移动中可以改速度后「套用新速度」,不用停下重来。

路径来源

四个免费免注册的引擎可切换:OSRM 公用 demo(默认)、OSRM FOSSGIS、Valhalla、BRouter。任一引擎失败时该段自动改走直线,也可直接勾「使用直线路径」。多点路径有「最佳顺序」一键算出最短走访顺序。

连接

  • USB:插上自动连接,iPhone 锁定屏幕不受影响。拔除约 4 秒内检测,重插自动恢复。
  • WiFi Tunnel(iOS 17 以上):自动检测用 mDNS,找不到再扫描局域网。连过的 IP 会记住,可「钉选」设备自动连接与重试。
  • 多设备:最多同时三台,所有动作同步套用,随机漫步走一样的路线。

地图与坐标

  • 图层:OSM、Google 瓦片(测试)、ESRI 街道与卫星、OpenFreeMap Liberty / Bright / Positron、VersaTiles、NLSC 台湾电子地图、GSI 日本地理院地图。全部免 API key。
  • 状态列显示当前模拟位置的国旗、地名、天气与温度,跨时区时标出时差。
  • 坐标收藏:自动带入地名与国旗,可分类、排序、拖动,JSON 与 GPX 导入导出,数万笔显示在地图上也不卡。
  • 路线可分类保存并直接加载,支持 GPX 与 JSON。
  • 地址搜索:免费来源(OpenStreetMap 或 Photon),或自备 Google Geocoding 密钥。
  • 用户图示可换成 6 组内建角色或上传自己的 PNG。

手机网页操控

按状态列的「手机操控」会显示局域网网址与 6 位数 PIN,手机浏览器输入后可瞬移、导航、搜索地址、输入坐标、停止与还原。手机要与电脑在同一个 WiFi,电脑防火墙放行 8777 port。

其他

  • 一键还原清除虚拟定位。「停止」只结束移动,定位仍保留,要恢复真实 GPS 请按还原。
  • Cooldown 依瞬移距离自动计算冷却时间。
  • 界面可在简体中文与 English 之间切换。
  • 所有资料存在 ~/.locwarp/,重新安装不会遗失。
